# SmartLuggage AI

A frontend-only Smart Online Luggage Transportation System powered by simulated AI logic, localStorage data, and responsive dashboard UI.

## Features

- Landing page with hero, stats, and features
- Dashboard with summary cards, recent bookings, AI recommendation, and active deliveries
- Booking form with AI price estimation
- Luggage management with add/delete actions
- Tracking page with timeline simulation
- AI assistant chat using predefined responses
- Cost estimator
- Route optimization simulation
- Notifications center
- Reports with Chart.js charts
- Transportation partners section
- Profile and settings pages
- Support page with FAQ and support form
- Dark mode and responsive layout

## Run

Open `index.html` directly in a browser.

## Files

- `index.html` — main application entry point
- `css/style.css` — core styling
- `js/app.js` — app logic, sample data, and localStorage-driven functionality

## Notes

This is a frontend-only demo and does not use a backend or external AI API.
